## Your Task — Stage: `{{current_stage}}`

### If current_stage is `DESIGN_DRAFT`

You must draft the initial frontend design contract for `{{feature}}`. Your output must be a valid JSON object matching `context/design_contract.schema.json`.

Follow these rules:
1. **Component Tier**: Determine if the task requires a `generic` (dumb UI), `layout` (positioning/combining common elements), or `view` component (forms or page-level overrides). Refer to `context/conventions_ref.md` for definitions.
2. **Vuetify Components**: Select appropriate Vuetify 3 components (e.g. `v-btn`, `v-card`, `v-text-field`) instead of raw HTML elements.
3. **Design Tokens**: Identify the design tokens you need. You MUST only use CSS variables that exist in the **Token Registry** (e.g., `--primary-color`, `--spacing-md`). Do not invent new token names.
4. **SVG Wireframe**: Generate a clean, responsive SVG wireframe representing the layout. Use `<rect>`, `<text>`, `<circle>`, etc. Render mock borders, text, and buttons styled with colors matching your design tokens. Set `review_mode` to `"image"`.
5. **Output**: Your main output must be the structured design contract inside the `=== DESIGNER CONTRACT ===` block.

### If current_stage is `DESIGN_REVIEW`

You must revise the design contract based on the critique and comments received. The critique comments are supplied in the `{{retry_errors}}` or `{{context}}` sections.

Follow these rules:
1. Read the critique comments carefully.
2. Update the design contract's fields (especially the SVG wireframe, design tokens, or component tier selection) to address the feedback.
3. Increment the `iteration` number by 1.
4. Set the `review.status` to `"pending"`.
5. Summarize the changes you made in the `review.notes` field.
6. Output the revised design contract JSON in the `=== DESIGNER CONTRACT ===` block.

## Output Format

Your response must contain the completed design contract JSON block formatted exactly as shown below:

```text
=== DESIGNER CONTRACT ===
{
  "component_name": "MyComponent",
  "tier": "generic",
  "vuetify_components": ["v-btn", "v-icon"],
  "design_tokens": {
    "background": "--surface-color",
    "color": "--primary-color",
    "padding": "--spacing-md"
  },
  "states": ["hover", "active"],
  "animation_spec": "Smooth fade on hover (transition-smooth)",
  "wireframe": {
    "svg_content": "<svg viewBox=\"0 0 200 100\">...</svg>",
    "review_mode": "image"
  },
  "review": {
    "status": "pending",
    "iteration": 1,
    "notes": "Initial draft"
  },
  "code_files": [
    "frontend/src/components/common/MyComponent.vue"
  ]
}
=== END DESIGNER CONTRACT ===
```

The orchestrator will parse this block to update the `contract` field in `plugin_state.json`.
